# A Dark Forest Godot-CSV lockit toolkit

Deterministic, dependency-free tools for the A Dark Forest `localization.csv` (Godot 4 CSV
translation table — key + context + locale columns). **Read the chart first:**
`vault/lockits/a-dark-forest/profile.md` (confirmed anatomy), `variables.md` (constructs +
labeling), `structure.md`. All scripts live in `scripts/a-dark-forest/` and import the shared
reader `csv_parse.py`. Run from `scripts/a-dark-forest/`.

> **If the lockit's structure changed, re-profile before trusting these** (`/profile a-dark-forest`).
> The `--audit` drift check (below) tells you if new/unknown constructs have appeared.

## Anatomy in one line
A flat CSV: columns `key,description,en,zh,fr,pt,pl,ua,th,es`. `key` = `namespace:name`
(identity, **not unique** — one dup). `description` = translator context + a closed tag DSL
(`[EMPTY]`/`[noun]`/`[verb]`/`[DEPRECATED]`), **not a locale**. `en` = source; 7 translations
(`ua` partial). Cell values have three shapes: **scalar**, **JSON-array** (multi-value, e.g.
`["Yes","No"]` — element count is a cross-locale invariant), or **empty** (intentional iff
`[EMPTY]`). Placeholders: positional `{0}`–`{3}` + literal `\n`. **No in-game markup.**

## Scripts
| Script | Use | Invocation |
|---|---|---|
| `csv_parse.py` | core reader / census self-check | `python3 csv_parse.py <csv>` |
| `report.py` | namespaces, shapes, honest completeness | `python3 report.py [csv]` |
| `inventory.py` | construct inventory (+ origin) | `python3 inventory.py [csv]` |
| `extract.py` | slice by namespace/key/shape/untranslated (`[DEPRECATED]` excluded by default) | `python3 extract.py [csv] --namespace ui_label --format json` |
| `arrays.py` | expand JSON-array cells + length-parity check | `python3 arrays.py [csv] [--key <key>]` |
| `validate.py` | single-file structural check | `python3 validate.py [csv] --warn` |
| `validate_placeholders.py` | **cross-locale** invariants ({N} + array length) | `python3 validate_placeholders.py [csv] [--locale pl] --warn` |
| `labels.py` | **labeling registry + drift audit** | `python3 labels.py` · `python3 labels.py --audit <csv>` |
| `tests/test_toolkit.py` | dual-mode tests (synthetic + real census) | `python3 tests/test_toolkit.py` |

## Labeling & drift (project rule)
`labels.py` is the single source of truth: every construct is tagged `format` (CSV/JSON/Godot
spec, portable) / `project` (A-Dark-Forest-specific) / `unknown` (flagged). Run
`labels.py --audit <csv>` whenever the data changes — anything `unknown` means the lockit gained
a construct our system doesn't know yet (a new description tag, a new control token, a new
column); extend the registry deliberately, don't let it pass silently.
