# Veloren Fluent lockit toolkit

Deterministic, dependency-free tools for the Veloren `.ftl` localisation set. **Read the chart
first:** `vault/lockits/veloren/profile.md` (confirmed anatomy), `variables.md` (placeholders +
labeling), `structure.md`. All scripts live in `scripts/veloren/` and import the shared reader
`ftl_parse.py`. Run from `scripts/veloren/`.

> **If the lockit's structure changed, re-profile before trusting these** (`/profile veloren`).
> The `--audit` drift check (below) tells you if new/unknown constructs have appeared.

## Anatomy in one line
A Fluent file is a keyed tree: **messages** `id = value` (ids globally unique), **terms**
`-id = value`, and **attributes** `.name = value` in four labeled roles — metadata
(`.desc/.stat`), variant-array (`.aN`), gender (`.fem/.masc/.neut`), enum (named lookup). Values
carry placeables `{ $var }`, selectors `{ $x -> … }`, functions `{ TAIL() }`, refs, `{""}` blanks.

## Labeling & drift (project rule)
`labels.py` is the single source of truth: every construct is tagged `fluent` (format spec,
portable) / `project` (Veloren-specific) / `unknown` (flagged). Run `labels.py --audit <dir>`
whenever the data changes — anything `unknown` means the lockit gained a construct our system
doesn't know yet; extend the registry deliberately, don't let it pass silently.

## Bundle export (normative output — handle differently)
`export_bundle.py` is the one script whose output is a **contract, not a report**: the sibling
The downstream consumer stores every annotation as a character offset into the `source_text` this
script emits, and never opens the .ftl again. So two rules hold:
- **Re-export must stay byte-identical.** `source_text` uses the reader's documented
  normalisation (strip + join with LF), declared in `producer_version`; the payload sha256 is
  pinned in the tests. If a parser change moves it, fix the parser or re-pin *deliberately* —
  a silent re-hash invalidates stored annotations.
- **It refuses to export over `validate.py` ERRORs** (`--force` overrides, loudly). Unbalanced
  braces make the scanner drop a placeable, so the row would claim "no placeholder here" over a
  live substitution point — and `placeholders: []` is a positive assertion in that contract.

`origin: unknown` is passed through **unchanged** — it is the drift signal telling the consumer
not to trust a mask and to escalate to a reviewer. Never collapse or "fix" it. Fluent only: the
v0.2 contracts cannot represent Clausewitz or Godot-CSV lockits, and the script refuses them.

## Trust boundary
Generated by this project; trusted after GATE 2 (session 002). Scripts read/write local files
only, no network. On third-party/upstream GPL data we **surface** defects, never edit them.
