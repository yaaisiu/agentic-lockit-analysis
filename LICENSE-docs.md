## What is NOT covered by these licences

This repository documents a method for analysing third-party localisation files, using
four real games as worked examples. **No third-party game content ships in this repository.**

- Real lockit files and any acquired game source live under `data/` and `sources/`, which
  are **gitignored** and never committed. Analysis notes in `vault/lockits/` describe
  structure using **synthetic examples and identifiers only** — not real source strings.
